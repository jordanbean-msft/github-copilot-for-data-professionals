# GitHub Copilot for Data Professionals

Public-facing demo kit showing how GitHub Copilot helps data engineers and data scientists accelerate supply-chain data work: ingestion, data quality, Spark transformations, SQL analytics, feature engineering, model experimentation, documentation, and test generation.

This repo pairs with the deck in `deck\github-copilot-for-data-professionals.pptx`.

The deck build uses a Microsoft-branded template and official product icons for GitHub, GitHub Copilot, and Microsoft Fabric.

## Audience

- Data engineers building Microsoft Fabric lakehouse pipelines
- Data scientists preparing features and experiments
- Analytics engineers writing SQL and tests
- Technical leaders evaluating Copilot beyond application development

## What You Can Demonstrate Live

| Demo | Workflow | File | Copilot value |
|---|---|---|---|
| 00 | Generate supply-chain data | `examples\python\00_generate_sample_data.py` | Ask Copilot to synthesize purchase orders, shipments, inventory snapshots, and edge cases |
| 01 | Ingest & profile data | `examples\python\01_ingest_profile.py` | Ask Copilot to explain supply-chain schemas, detect anomalies, and create reusable profiling helpers |
| 02 | Data quality checks | `examples\python\02_data_quality_checks.py` | Ask Copilot to generate validation rules and quarantine logic for operational data |
| 03 | Spark transformations | `examples\python\03_fabric_spark_transform.py` | Ask Copilot to translate pandas supplier and inventory logic into PySpark/Fabric lakehouse code |
| 04 | SQL analytics | `examples\sql\04_fabric_sql_analytics.sql` | Ask Copilot to write, tune, and explain SQL for late shipments and inventory risk |
| 05 | Feature engineering & ML | `examples\python\05_feature_engineering_ml.py` | Ask Copilot to create supply-chain risk features, evaluate models, and interpret results |

## Quick Start: Microsoft Fabric

1. Create or open a Fabric workspace and Lakehouse
2. Upload the CSV files generated by `00_generate_sample_data.py` into the Lakehouse `Files/copilot-demo/` folder, or run the notebook cells to generate them
3. Import the notebooks from `examples\notebooks`
4. Attach the notebooks to your Lakehouse
5. Run the cells in order and use the facilitator prompts in `facilitator\demo-runbook.md`

## Recommended Copilot Demo Pattern

For each workflow, show the same four-step loop:

1. **Understand**: Ask Copilot to explain unfamiliar data or code
2. **Generate**: Ask Copilot to draft transformations, SQL, or tests
3. **Refine**: Ask Copilot to handle edge cases, performance, and readability
4. **Document**: Ask Copilot to create lineage notes, comments, and runbook steps
